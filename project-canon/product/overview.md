# Product Overview

Status: baseline / to be confirmed

Source: current repo inspection.

`freediving.ph` is an open-source social platform for the freediving community in the Philippines.

Current repo-level product areas explicitly described in codebase entry files:

- social profiles and user presence
- private messaging
- buddies and groups
- discussion/forum surfaces
- dive-site exploration and map/discovery
- events
- competitive records

The repo is structured as a multi-surface product, not a single-page feature app.

Not yet claimed here:

- production readiness
- full feature completeness across all named areas
- live deployment/runtime proof for every surface
