# AI Project Contract

Project: freediving.ph

This project follows the workspace default:

Ticket-First, Docs-Grounded, Local-Verified Closed Loop.

## Source of truth

- `project-canon/` is the durable project source of truth.
- root `docs/` is legacy/reference material only during adoption and must not be treated as a normal final-state docs surface.
- `.ai-project.md` defines local project agent rules.
- Parent `.ai/` defines shared workflow.
- `.ai-local/core-snapshot.md` is fallback only.
- Code and tests are executable truth.

## Project Index

The committed workspace project index template is:

- `.ai/workspace/project-index.example.md`

For local/private project routing, use:

- `.ai/workspace/project-index.local.md`

Prefer `project-index.local.md` when present. If it is absent, use `project-index.example.md` only as a format reference and infer the target project from the user's explicit path or instruction.

## Verification

Default: Local-Verified.

Project-specific verification rules will be filled in a later phase.

## Docs update rule

Update `project-canon/` only when durable project truth changes.
Do not update `project-canon/` for styling-only changes, one-off implementation details, temporary debugging notes, noisy logs, or root-level docs preservation.
